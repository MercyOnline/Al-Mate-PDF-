Quality

The app overlays one PNG onto the original PDF pages. It does not rasterize the page, so source text and images keep their original quality.

Smart skip

A low-resolution render is used only to inspect the footer zone. Pages with detected content in that area are left unchanged.

File size

The footer image is embedded once and reused. Object streams are enabled to limit unnecessary size growth while preserving the PDF.
